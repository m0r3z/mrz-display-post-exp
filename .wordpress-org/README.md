# Assets WordPress.org

Visuels destinés au répertoire wordpress.org. **Non distribués dans le zip du plugin** (exclus via `.distignore`) — au moment d'une publication, leur contenu est poussé dans le dossier `assets/` du SVN wp.org.

| Fichier | Dimensions | Usage |
|---|---|---|
| `icon-256x256.png` | 256×256 | Icône du plugin (répertoire + écran des mises à jour) |
| `icon-128x128.png` | 128×128 | Icône standard (fallback) |
| `banner-1544x500.png` | 1544×500 | Bannière haute densité (Retina) |
| `banner-772x250.png` | 772×250 | Bannière standard |

Captures d'écran à ajouter ici (`screenshot-1.png`, …) en regard d'une section `== Screenshots ==` dans `readme.txt`.

> L'icône du **menu admin** est un fichier distinct : `assets/menu-icon.svg` (SVG monochrome, embarqué dans le plugin, coloré via CSS `mask-image`).
